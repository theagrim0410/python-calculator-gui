# Calculator Application

## Description
This is a simple GUI-based calculator built using Python and Tkinter. It allows users to perform basic arithmetic operations such as addition, subtraction, multiplication, division, exponentiation, modulus, and logarithm calculations. The application features a user-friendly interface with a dark-themed background.

## Features
- Perform basic arithmetic operations (+, -, *, /, **, %)
- Calculate logarithm using `log` operator
- Handles division by zero errors
- Prevents empty input fields
- Provides a clean and visually appealing GUI

## Installation
1. Ensure you have Python installed on your system.
2. Install the required dependencies:
   ```sh
   pip install tk
   ```
3. Download or copy the `calculator.py` file.

## How to Use
1. Run the script:
   ```
   python calculator.py
   ```
2. Enter the first number in the corresponding input field.
3. Enter the second number.
4. Specify the operator (`+`, `-`, `*`, `/`, `**`, `%`, or `log`).
5. Click the **Calculate** button to see the result.
6. Click the **Close** button to exit the application.


## Technologies Used
- Python
- Tkinter (GUI Library)
- Math Library (for logarithm calculations)
